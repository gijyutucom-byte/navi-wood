# 技術科「材料と加工」学習Webアプリ

中学校技術・家庭科（技術分野）の「材料と加工の技術」に関する内容を、図や操作シミュレーション、確認クイズを通して学習するWebアプリ集です。

生徒が学習に使用する教材に加え、技術科教員が木工機械の安全な操作を確認するための教材も収録しています。各アプリはHTMLファイル単体で動作し、特別なインストールやサーバー環境を必要としません。

## 収録内容

| 区分 | アプリ | 主な学習内容 | ファイル名 |
| --- | --- | --- | --- |
| 基礎 | 図法の基本 | 等角図、キャビネット図、第三角法 | `zuho.html` |
| 基礎 | 木材の基本 | 木材各部の名称、年輪、繊維方向 | `wood_basic.html` |
| 基礎 | 木材の種類 | 代表的な針葉樹・広葉樹の特徴、比較、確認クイズ | `wood_zukan.html` |
| 基礎 | 木材の反り | 含水率や木取りによる反りの違いと直し方 | `wood_sori.html` |
| 生徒向け | ベルトサンダー | 各部の名称、安全確認、加工操作 | `belt_sander.html` |
| 生徒向け | ボール盤 | 各部の名称、材料の固定、安全な操作、確認クイズ | `drillpress.html` |
| 教員向け | 丸鋸昇降盤 | 横引きを中心とした段取り、安全操作、指導上の注意 | `shokoban.html` |
| 教員向け | 自動鉋盤 | 各部の名称、安全な使い方、加工前後の確認 | `jidokanna.html` |

## 使用方法

1. このリポジトリをダウンロードまたはクローンします。
2. すべてのHTMLファイルを同じフォルダに置きます。
3. `index.html` をWebブラウザで開きます。
4. メニューから学習する内容を選びます。

```bash
git clone <このリポジトリのURL>
cd <リポジトリ名>
```

その後、`index.html` をブラウザで開いてください。GitHub Pagesに公開する場合は、リポジトリのルートに各ファイルを配置し、Pagesを有効にします。

## 動作環境

- HTML5、CSS、JavaScriptに対応した一般的なWebブラウザ
- Google Chrome、Microsoft Edge、Safari、Firefoxの各最新版を推奨
- インターネット接続は原則不要です
- PCまたはタブレットでの利用を推奨します

## 授業での活用例

- 授業の導入や説明時に、教員が大型提示装置で操作する
- 生徒が1人1台端末を使って、個別に操作・確認する
- 木工機械を使用する前の安全指導や振り返りに活用する
- 確認クイズを用いて、基本事項の理解状況を確かめる
- 教員研修で、昇降盤や自動鉋盤の操作手順を確認する

## 安全上の注意

本アプリは、木材加工や木工機械に関する学習・安全指導を支援する教材です。実際の機械操作に必要な実技指導、取扱説明書の確認、施設・設備ごとの安全管理に代わるものではありません。

実際に機械を使用する際は、機器の取扱説明書、学校や設置施設の安全基準、教員の指示に従ってください。特に教員向け教材で扱う丸鋸昇降盤および自動鉋盤は、生徒による操作を想定していません。
